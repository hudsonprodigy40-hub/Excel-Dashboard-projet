## 🗂️ Dashboard Structure / Sheets
The workbook is organized into the following tabs:
1. **Dashboard:** The main interactive visual interface for presentations and daily monitoring.
2. **Pivot Tables:** Houses the underlying aggregation and logic supporting the charts.
3. **Data Source:** Raw data tables imported and cleaned for analysis.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel** (Advanced Formulas, Pivot Tables, Pivot Charts, Slicers)

---

## ⚙️ How to Use
1. Download the latest `.xlsx` file from this repository.
2. Open the file in Microsoft Excel 
3. Navigate to the **Data Source** tab and paste your updated raw data into the table.
4. Go to the **Dashboard** tab, right-click any pivot chart or table, and select **Refresh** to update all visuals instantly.
